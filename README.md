# Paper Mill Management System
An inventory and production management application developed for the **CSE213: Object-Oriented Programming** course at **Independent University, Bangladesh (IUB)**.

## 📋 Project Overview
This application is designed to streamline the operations of a Paper Manufacturing Mill. It features a role-based access system to ensure that different departments (Management, Inventory, Production, and Employees) can interact with the data relevant to their tasks.

## 🚀 Key Features
* **Role-Based Login:** Secure access for different user types.
* **Inventory Dashboard:** Real-time tracking of raw materials and finished paper products.
* **Production Monitoring:** Tools for Production Supervisors to oversee mill operations.
* **Employee Management:** View and manage staff records and shifts.
* **Interactive UI:** Built using JavaFX and Scene Builder for a modern user experience.

## 🛠️ Tech Stack
* **Language:** Java (JDK 21+)
* **Framework:** JavaFX
* **Build Tool:** Maven
* **Version Control:** Git & GitHub
